# MusicReview - Музыкальная платформа

Веб-сайт для прослушивания, загрузки и рецензирования музыкальных композиций.

## 🚀 Функционал

- **Авторизация и регистрация** пользователей
- **Загрузка музыки** на сайт (MP3, WAV, OGG)
- **Прослушивание треков** онлайн
- **Скачивание музыки**
- **Система рецензий** с оценками (1-10)
- **Создание плейлистов**
- **Избранные треки**
- **Статистика** (прослушивания, скачивания, рейтинги)

## 📋 Технологии

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP 8.0+
- **База данных:** MySQL 5.7+ / MariaDB
- **Стиль:** Темная тема в стиле Spotify

## 🛠️ Установка

### 1. Требования

- PHP 8.0 или выше
- MySQL 5.7 или выше
- Web-сервер (Apache/Nginx)
- Расширение PDO для PHP

### 2. Настройка базы данных

```bash
# Импортируйте схему базы данных
mysql -u root -p < database.sql
```

### 3. Конфигурация

Отредактируйте файл `includes/config.php`:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'music_site');
define('DB_USER', 'root');
define('DB_PASS', 'ваш_пароль');
define('SITE_URL', 'http://localhost');
```

### 4. Права доступа

Убедитесь, что папки для загрузок доступны для записи:

```bash
chmod -R 755 assets/uploads/
```

### 5. Запуск

Разместите файлы на веб-сервере и откройте сайт в браузере.

## 🗄️ База данных

### Основные таблицы:

- **users** - пользователи
- **tracks** - музыкальные композиции
- **reviews** - рецензии и оценки
- **playlists** - плейлисты
- **playlist_tracks** - треки в плейлистах
- **favorites** - избранные треки
- **sessions** - сессии пользователей
